# Импорт и повторное использование рецептур

В «Рецептурах» нажмите «Загрузить базу». Если библиотека пустая, панель импорта уже открыта. Скачайте шаблон и сохраните таблицу как CSV UTF-8. Поддерживаются разделители `;`, запятая и табуляция, кавычки CSV и переносы строк внутри них.

| Столбец      | Значение                                                               |
| ------------ | ---------------------------------------------------------------------- |
| pantone      | Номер или имя собственного цвета; обязательно                          |
| name         | Название рецептуры; если пусто, используется Pantone                   |
| ink          | Название базовой краски; обязательно                                   |
| code         | Код базы; если указан, база ищется по производителю и коду             |
| manufacturer | Производитель или обозначение системы стандартных баз; обязательно     |
| grams        | Положительная масса компонента, до 3 знаков после запятой; обязательно |
| source       | OWN, SUPPLIER или PANTONE; пустое значение означает OWN                |
| sourceNote   | Документ, редакция, примечание; обязательно для SUPPLIER и PANTONE     |
| version      | Необязательный положительный номер для разделения версий в файле       |

Одна строка — одна базовая краска. Если исходный документ содержит массовые проценты, внесите их числами в `grams`: получится рецепт на 100 г. В приложении он пересчитывается на нужную массу замеса.

Следующий пример исключительно синтетический, не формула Pantone и не инструкция для реального производства:

```csv
pantone;name;ink;code;manufacturer;grams;source;sourceNote;version
TEST 1;Тестовая смесь;Учебная база A;TEST-A;DEMO ONLY;80;OWN;Синтетический пример;1
TEST 1;Тестовая смесь;Учебная база B;TEST-B;DEMO ONLY;20;OWN;Синтетический пример;1
```

Строки объединяются по цвету, названию, источнику, примечанию и версии. Совпадающий состав не добавляется повторно; изменённый состав сохраняется следующей версией. Имеющиеся краски сопоставляются по производителю и коду, а при отсутствии кода — по производителю и имени. Автоматически созданная карточка базы не получает выдуманных измерений или калибровки.

Перед добавлением видны количество рецептур, компонентов, исходная масса и источник. Ошибка любой записи откатывает весь импорт. До 5 МБ и 12 000 строк за один файл. Изменённую таблицу можно импортировать снова. Для точного резервирования всех связей, фото и истории используйте JSON-копию в настройках: CSV предназначен для составов.

Откройте рецепт, укажите массу и нажмите «Создать заказ по рецептуре». Компоненты подставятся в исходный состав заказа. Проверьте фактические массы после взвешивания. Если масштаб приводит к компоненту меньше 0,001 г, увеличьте замес. «Карта замеса» открывает документ с граммами, процентами и графой для отметки взвешивания.

Стандартные формулы из [Pantone Formula Guide](https://www.pantone.com/products/graphics/formula-guide-coated-uncoated) должны содержать реальные базовые цвета и массовые доли. Обозначение PANTONE в CSV задаёт происхождение, а не подтверждает его автоматически. Укажите издание и источник в `sourceNote`.
