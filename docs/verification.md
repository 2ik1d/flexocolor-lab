# Проверка готовности первого теста

Проверено 26 октября 2026 года в Windows, Node.js 24.22.1. Это программная проверка; физические испытания на iPhone 13 и печатной машине не проводились.

## Автоматические проверки

| Проверка                                                    | Результат               |
| ----------------------------------------------------------- | ----------------------- |
| TypeScript strict, `tsc -b`                                 | Успешно                 |
| Production build, `vite build`                              | Успешно                 |
| Vitest                                                      | 81 / 81                 |
| Playwright Chromium, мобильный viewport iPhone 13           | 11 / 11                 |
| Playwright WebKit, мобильный viewport iPhone 13             | 11 / 11                 |
| Цикл нескольких Pantone на `/flexocolor-lab/`               | 6 / 6                   |
| Воспроизводимая установка `pnpm install --frozen-lockfile`  | Успешно                 |
| Service worker и офлайн-перезагрузка с локальной рецептурой | Успешно в обоих движках |

Vitest включает:

- sRGB transfer, XYZ, белый/чёрный Lab, Bradford, ΔE76;
- все 34 дополнительных пары Sharma–Wu–Dalal (2005), ΔE00 в обоих направлениях с точностью 0,00005;
- точные десятичные массы, проценты, масштабирование с сохранением итога, последовательные добавки и недопустимый ввод;
- создание/загрузка партии, пробы, события добавок и эксперимент;
- экспорт/импорт JSON, повреждённые ссылки и настройка, сохранение старой базы при отказе валидации;
- настоящую миграцию IndexedDB из v1/v3 в v4 через fake-indexeddb, а также перенос JSON-копий v2/v3 с созданием отдельных заказов;
- фильтрацию пикселей, испорченное изображение, отсутствие камеры и отказ доступа;
- CSV Lab/спектры и ошибочные входные данные;
- независимые составы цветов, несколько атомарных добавок, неизвестный исходный состав, изменение фактической смеси без потери истории;
- выводы о приближении/удалении от эталона, несовместимые условия, смену эталона и отсутствие прошлой пробы;
- безопасный отказ ColorCorrectionEngine без добавок и выдуманного прогноза.

В каждом браузере проверяются одиннадцать сценариев:

1. Два фото, масштаб, ROI, анализ, сброс результата при изменении ROI, отсутствие камеры.
2. Добавление своей краски, серия контрольных снимков, сохранение/активация и повторная загрузка профиля.
3. Блокировка сравнения Lab при разных условиях и отклонение повреждённого импорта.
4. Мобильный/настольный вид, отсутствие горизонтального переполнения, снимки экрана.
5. Новая партия с двумя красками → общий снимок → два ROI → сохранённая проба → добавка 25,5 г → масса 1025,5 г → следующая Lab-проба → экспорт → подтверждённое восстановление → повторная загрузка истории.
6. Повреждённый PNG и отказ getUserMedia.
7. Service worker → сохранённая рецептура → отключённая сеть → успешная перезагрузка.
8. Масштабирование рецептуры и сохранение новой версии.
9. Несколько Pantone при создании заказа; известный состав → две добавки одной операцией → новая проба ближе, следующая дальше; изоляция проб и масс по цветам.
10. Фотоаналитика без известного исходного состава: первая проба, две добавки, следующая проба, вывод «Ближе», JSON-экспорт и восстановление без выдуманной общей массы.
11. Добавление нескольких Pantone в существующий заказ, изменение номера, запрос нового эталона и сохранение прежних проб.

Тестовые картинки создаются из явно синтетических однотонных полей. Они проверяют программный путь обработки, но не точность на реальных оттисках. Снимки экрана визуально просмотрены для мобильной и настольной компоновок. В CI тестовые traces сохраняются при ошибках; пользовательские данные туда не попадают.

## Что проверить на реальном устройстве

- iPhone 13 / актуальная Safari: фотосъёмка, доступ и отказ, EXIF, широкогамутный ICC, используемый формат HEIC/JPEG и визуальная ориентация;
- установка через «На экран Домой», офлайн после полного закрытия приложения, обновление PWA с сохранённой базой;
- длительная работа, нагрев, большие серии фото и реальные ограничения IndexedDB;
- повторяемость на конкретном освещении, физическом веере и материалах; сравнение с независимыми измерениями спектрофотометра;
- метамерия, блики, флуоресценция и влияние подложки; отсутствие абсолютной калибровки камеры;
- производственные критерии ΔE00 и качество экспериментальных данных.

WebKit на Windows и эмуляция экрана iPhone не заменяют эти испытания. Автоматические рекомендации по добавкам отключены; неопределённость реальной фотооценки пока не установлена.
