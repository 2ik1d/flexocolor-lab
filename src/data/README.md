# Экранный справочник Coated

Снимок данных подготовлен 26 октября 2026 года. `coated.json` содержит 3 443 уникальных номера с суффиксом C: 3 219 записей опубликованного набора 2024 года и 224 новых номера 6225–6448 из публикации 2026 года. Число записей справочника не является заявлением о числе цветов в официальном печатном издании Formula Guide 2026.

Источники:

- [aj90909 / unofficial-pantone-solid-coated-2024-v5](https://github.com/aj90909/unofficial-pantone-solid-coated-2024-v5), файл `output.json`. Автор описывает получение Lab из изображений через Photoshop; это экранные приближения, а не спектрофотометрические измерения образцов.
- [PantoneConverter: New Pantone Colors 2026](https://pantoneconverter.com/new-pantone-colors-2026/) — опубликованные HEX для всех 224 новых номеров, только coated. Забираются числовые значения из JSON страницы; изображения и тексты статьи в проект не копируются.

Для набора 2024 Lab D50 переводится в XYZ D50, адаптируется Bradford к D65 и переводится в sRGB для отображения. Для новых HEX справочные Lab рассчитываются через существующий sRGB → Lab D50 модуль. В карточке сохраняются источник и год набора. Эти значения не подменяют фото эталона, приборное измерение или калибровку. Все встроенные записи имеют пустую коллекцию измеренных эталонов.

Файл входит в отдельный chunk сборки и precache PWA. В IndexedDB хранятся собственные изменения и измерения оператора; при чтении они объединяются со встроенным справочником. Встроенный каталог не раздувает пользовательские резервные копии.

Обновление при доступе к сети:

```sh
node scripts/build-fan.mjs
```

Скрипт проверяет структуру источников и наличие 224 записей нового набора. После обновления выполнить `pnpm test`, сборку и браузерные тесты. Рецептуры смешивания не выводятся из HEX/Lab: реальные составы берутся из сохранённых заказов, записей оператора и рецептур поставщика.
